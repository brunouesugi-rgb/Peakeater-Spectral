# Download Peakeater Spectral

The Windows VST3 package is available from the GitHub Releases page:

https://github.com/brunouesugi-rgb/Peakeater-Spectral/releases

Download the latest `Peakeater-Spectral-Windows` ZIP, extract it, and copy the
complete `Peakeater Spectral.vst3` bundle to:

```text
C:\Program Files\Common Files\VST3
```

Restart the DAW. In Ableton Live, use `Preferences > Plug-ins > Rescan` if the
plug-in does not appear.

The source code, GPL-3.0 license, release notes, and build instructions are in
the repository. Peakeater Spectral is a modified derivative of the
open-source PeakEater project.
